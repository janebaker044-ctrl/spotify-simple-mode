SPOTIFY SIMPLE MODE
Student Project – IS5488 Assessment 3

PROJECT DESCRIPTION
Spotify Simple Mode is a simple website prototype
designed to make navigation easier for new Spotify users.

PAGES
1. Home – The main page.
2. Search – Allows users to enter a song or artist.
3. My Playlists – Allows users to select example playlists.

TECHNOLOGIES USED
- HTML – Website structure.
- CSS – Website design and styling.
- JavaScript – Interactive features.
- Browser Local Storage – Remembers the last selected playlist.

HOW TO RUN THE WEBSITE
1. Open the Website Project folder.
2. Find the index.html file.
3. Double-click index.html to open it in a web browser.
4. Use the navigation links to visit the other pages.

DEVELOPMENT TOOL
Visual Studio Code.

PROJECT TYPE
Interactive student prototype.
